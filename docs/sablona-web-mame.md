# Counter-šablona na odpověď „web už máme"

Použití: RUČNĚ (nebo polo-ručně) jako odpověď, když někdo na outreach odepíše,
že web má. Cíl: proměnit odmítnutí v modernizační konverzaci. Vždy si PŘED
odesláním jejich web otevřít a doplnit JEDEN konkrétní postřeh — bez něj
šablonu neposílat, působila by jako automat.

---

Když už jsme ale v kontaktu: teď jsem si {DOMENA} prošel pořádně a jedna
věc mě praštila do očí — {KONKRETNI_POSTREH}. Jinak {NECO_POCHVALIT}.

Kdyby vás někdy zajímalo web osvěžit — rychlost, mobil, viditelnost na
Googlu — rád připravím nezávaznou ukázku, jak by mohl vypadat. A jestli ne,
nebudu vás už obtěžovat a přeji, ať se daří.

{PODPIS}

- otevírací doba/ceník je z roku …
